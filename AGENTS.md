
# NON-NEGOTIABLE RULES

## MUST NOT

- Do not implement a new solution before checking whether an existing
  project resource already provides the required functionality.
- Do not modify code without first establishing sufficient context. 

## MUST 
- Always leverage existing project resources before implementing new
  solutions, including dependency/configuration files located at the
  project root.
- Establish sufficient project context before taking implementation
  actions. Inspect the relevant project structure, existing
  implementations, and dependencies first. 
- When implementing code, organize responsibilities into appropriately
  scoped modules/files and follow the Single Responsibility Principle.
